# System Design Primer

A complete reference and decision framework for building, scaling, and designing distributed systems, high-availability architectures, and large-scale web services.

## Core Topics & References
- **Scalability Patterns**: Horizontal vs Vertical scaling, Load balancers, Caching layers (Redis, Memcached), CDNs, Asynchronous processing, Message queues.
- **Databases & Storage**: SQL vs NoSQL, Replication, Sharding, Federation, Denormalization, ACID vs BASE.
- **Communication Protocols**: REST, GraphQL, gRPC, WebSockets, Server-Sent Events.
- **System Design Solutions & Case Studies**:
  - `solutions/system_design/pastebin/`: Pastebin architectural design
  - `solutions/system_design/mint/`: Mint personal finance tracker & aggregator
  - `solutions/system_design/scaling_aws/`: Scaling to millions of users on AWS
  - `solutions/object_oriented_design/`: Object oriented design patterns (LRU cache, call center, parking lot, chat server).
