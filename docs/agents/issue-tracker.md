# Issue tracker: Local Markdown

The active platform specification and issues live under `.scratch/language-learning-platform/` and are committed with the code.

## Conventions

- The locked platform spec is `spec.md`.
- Implementation issues are separate numbered files under `issues/`.
- Product Pack work is tracked as a child issue/spec and cannot redefine Platform Core policy.
- `Status:` uses the mapping in `triage-labels.md`.
- Decisions, risks, evidence, and verification output are appended to the relevant issue rather than held only in chat.
- An issue is complete only when every declared exit gate has actual evidence.
- The superseded `.scratch/local-ai-ielts-coach/` path must not be recreated; Git history preserves the earlier IELTS-first draft.
