# Issue tracker: Local Markdown

Issues and specs for this repository live under `.scratch/` and are committed with the code.

## Conventions

- One feature per `.scratch/<feature-slug>/` directory.
- The locked product spec is `spec.md`.
- Implementation issues are separate files under `issues/`, numbered from `01`.
- `Status:` uses the mapping in `triage-labels.md`.
- Decisions, risks, evidence, and verification output are appended to the relevant issue rather than held only in chat.
- An issue is complete only when every declared exit gate has evidence.
