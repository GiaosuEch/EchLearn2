# Domain documentation

This is a multi-context repository.

- Start at `CONTEXT-MAP.md` and read only the glossary for the context being changed.
- Platform Core must never import Product Pack vocabulary or policies.
- Learning Domain owns generic curriculum, practice, assessment, feedback, memory, and planning language.
- Product Packs own track-specific tasks, rubrics, values, claims, generation rules, and entitlement declarations.
- Use the preferred terms and avoid listed aliases.
- Read accepted root ADRs before changing architecture, privacy boundaries, model distribution, deployment, or assessment claims.
- Add an ADR only for a hard-to-reverse trade-off that would otherwise surprise a future maintainer.
