# Triage labels

| Role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Scope has not been accepted. |
| `needs-info` | `needs-info` | A blocking decision is missing. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe to implement. |
| `ready-for-human` | `ready-for-human` | Requires human-only judgment or external evidence. |
| `wontfix` | `wontfix` | Deliberately not planned. |
| active extension | `in-progress` | Claimed and currently being implemented. |
| complete extension | `verified` | Exit gates have recorded passing evidence. |
