# Use browser-first tiered local AI with benchmark-selected artifacts

The product must work from a web URL without model API keys or mandatory local software, so local generation and transcription will run behind capability-based browser providers, with a deterministic coach when unsupported. Light, Standard, and Pro Local identify measured device/download/quality envelopes; no model is assigned to a tier until its commercial license, benchmark quality, runtime behavior, pinned artifact, and checksum pass review. A future localhost runtime connector remains possible behind the provider boundary but is not required for the zero-install product contract.
