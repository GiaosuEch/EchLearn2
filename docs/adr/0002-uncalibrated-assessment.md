# Treat every band-like result as an uncalibrated beta estimate

There is no lawful calibration set of examiner-rated learner Writing and Speaking responses available to this project. Any band-like output must therefore be labeled `uncalibrated beta estimate`, include confidence and learning evidence, and never resemble an official IELTS result; pronunciation is not assessed from transcript alone. The evaluation registry will measure behavior now and preserve a calibration seam for a future lawful human-rated dataset.
