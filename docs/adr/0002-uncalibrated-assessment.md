# Make calibration status explicit and owned by the assessment policy

The generic assessment engine records method, evidence, confidence, limitations, provenance, and calibration status without assuming an exam scale. Each Product Pack owns any track-specific value, disclosure, or abstention rule; for IELTS Academic, all band-like output remains an `uncalibrated beta estimate` until a lawful examiner-rated calibration set and validation protocol exist.
