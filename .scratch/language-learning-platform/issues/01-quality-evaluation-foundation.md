# Platform Quality Foundation

Status: in-progress
Phase: 1
Blocked by: none

## Outcome

Create a passing platform-first test seam and enforce generic AI honesty, no-random assessment, capability, structured-output, model-promotion, evaluation, and architectural-boundary contracts before production feature work.

## In scope

- Dependency-free test command using the existing Node toolchain.
- Generic Platform Core types/policies only.
- Negative-tested verification gates.
- Protected-path checks.

## Out of scope

- Model runtime dependencies/downloads.
- Product Pack or IELTS behavior.
- Curriculum/data/audio/migration changes.
- UI polish.

## Exit gates

- RED was observed before each behavioral implementation.
- Platform-first tests pass.
- No Product Pack terms/imports exist in Platform Core.
- Seeded fake/random violations fail their gates.
- Relevant build/lint/verify status is recorded honestly.
